# Security policy

This repository contains only a plugin manifest and documentation. It has no runtime code. The JustOnce service it points to (`https://mcp.justonce.ai/`) is operated by Bluesoul Technology.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

- Service or account security (mcp.justonce.ai, justonce.ai, the API): email **support@justonce.ai**.
- A problem with this manifest or its documentation: use GitHub's private vulnerability reporting on this repository, or the same address.

We acknowledge reports within two business days.

## Scope

- In scope: the JustOnce MCP server, its OAuth flow, and the justonce.ai application.
- Out of scope: third-party MCP clients (Cursor, Claude, ChatGPT, VS Code) — report those to their vendors.
